# 검증 기록

## 2026-09-30 · 1.4.0 · 흰색·초록·파랑 디자인

세 참고 이미지(앱디자인샘플.png, reference1.png, reference2.png)를 로컬에서 확인한 뒤 웹과 Android 공통 화면에 반영했습니다. 흰색 중심 화면, 초록색 기본 버튼, 파란색 선택 요소, 둥근 버튼, 넓은 단색 그림판을 적용했습니다. Pretendard 1.3.9를 웹·WebView·Android 네이티브 메뉴에 내장했습니다.

레이싱은 기존 Canvas 엔진을 유지하면서 비스듬한 지면 투영, 더 큰 선수, 선의 측면과 하이라이트, 실제 그림을 이용한 지면 그림자, 입체 펜스와 흰색·초록 허들을 적용했습니다. 경주 계산은 변경하지 않았습니다.

- 웹 프로덕션 빌드·TypeScript·ESLint 통과.
- 경주·카메라·오디오·방 상태 검사 43개 통과.
- 로컬 프로덕션 서버 WebSocket 검사 4개 통과: 직선 2인, 원형 4인, 지그재그·숲길 8인.
- Android APK 빌드, Java 검사 3개, Android Lint 통과 (오류 0개·경고 7개).
- 오프라인 번들의 WOFF2/TTF, 로컬 경로, 폰트 라이선스, 외부 API 미사용 검사 통과.
- 버전: 1.4.0, versionCode 6. 설치 파일: releases/DrawDerby-debug.apk.
- 브라우저 화면 조작·시각 QA와 휴대폰/에뮬레이터 실기기 검사는 이번 작업에서 수행하지 않았습니다.
- 사용자 승인 후 https://draw-derby.musicapp.workers.dev/ 에 배포 완료. 배포 버전: `308bea74-1ab4-42d0-95fc-b65f5cf13b9c`.
- 공개 CSS·페이지 JavaScript·Pretendard 파일이 로컬 검증 빌드와 SHA-256까지 일치함을 확인했습니다.
- 공개 서버 WebSocket 검사 4개 통과: 직선 2인, 원형 4인, 지그재그·숲길 8인. 검사 참가자는 종료 시 자동 퇴장했습니다.
- Android 온라인 화면은 다시 접속하면 적용됩니다. 오프라인 화면과 네이티브 메뉴는 새 APK 설치가 필요합니다.


## 2026-09-29 · 공개 웹앱 디자인 반영

https://draw-derby.musicapp.workers.dev/ 에 1.3.0과 같은 새 화면을 배포했습니다. Android의 기본 서버에 연결하는 온라인 화면에도 재접속 시 적용됩니다. 오프라인 화면은 기존에 생성한 1.3.0 APK에 포함되어 있습니다.

- 공개 페이지의 새 문구, 마스코트·CSS·JavaScript 파일의 배포 내용 확인.
- 공개 서버 2·4·8인 WebSocket 경주 검사 4개 통과.
- Google Play 출시로 범위를 확정했고 원본은 화면 이미지만 참고했다는 사용자 설명을 기록했습니다.
- 이 배포로 개인정보처리방침 등 남은 스토어 출시 검토가 완료된 것은 아닙니다. 상세 기록은 [디자인·출시 검토](../DESIGN_REVIEW.md)를 확인하세요.


## 2026-09-28 · 1.3.0 · 낙서 운동장 UI

웹과 Android 공용 화면을 흰색·블루 테마와 새 마스코트로 변경했습니다. 원본과 겹치던 문구와 ® 표시를 제거하고, 그림판·출발 패널·트랙 선택·대기방·경주·결과·도움말의 디자인을 통일했습니다. 저장·공유 안내와 웹 UI의 오픈소스 고지를 추가했습니다.

- 웹 검사 43개, 로컬 WebSocket 서버 검사 4개 통과.
- ESLint, TypeScript, 웹 프로덕션 빌드 통과.
- Android 오프라인 번들 검사 통과. 마스코트를 APK에 포함하며 외부 폰트 요청이 없습니다.
- APK 생성, Java 단위 검사 3개, Android Lint 통과. Lint 오류 0개·경고 7개.
- 버전: 1.3.0, versionCode 5. 기존 패키지 ID와 디버그 서명 설정을 유지했습니다.
- 이번 변경에 대한 실제 브라우저 시각 검사·실기기/에뮬레이터 UI 검사는 수행하지 않았습니다. 실기기의 60fps 동작을 보증하지 않습니다.
- 이 검증 시점에는 공개 서버 배포 전이었습니다. 2026-09-29 공개 반영 결과는 위 기록을 확인하세요.
- 정식 개인정보처리방침, UGC 신고·차단, 표현·상표 검토 등 남은 조건은 [검토 문서](../DESIGN_REVIEW.md)에 있습니다.

| Android Lint | 오류 0개, 경고 6개 |
| APK 생성 | `com.drawderby.app`, 1.2.1 (versionCode 4), 최소 API 26 / 대상 API 36 |

설치된 APK에서 기본 서버 주소 설정, 오프라인 네 트랙 완주·그림 저장, 경주 시 자동 가로 전환·캔버스가 화면 안에 표시됨·결과 화면에서 방향 복구, 연결 실패 후 오프라인 복귀, 정원 버튼의 2~8명 범위, Android 호스트와 WebSocket 참가자 7명의 경주 시작을 확인했습니다. 온라인 기기 검사는 PC에서 실행한 프로덕션 빌드를 `http://10.0.2.2:3000`으로 연결했습니다. 실제 휴대폰 검사는 수행하지 않았습니다.

공개 서버 `https://draw-derby.musicapp.workers.dev`에서도 2·4·8인 경주 동기화 검사 4개와 Android 앱이 기본 주소로 연결하는 8인 경주 검사 1개를 통과했습니다. 자동 배포 파일은 `.github/workflows/deploy.yml`이며 GitHub의 `CLOUDFLARE_API_TOKEN` Secret 등록이 필요합니다.

1.2.1에서는 회전할 때 `screenLayout`까지 처리해 화면 크기 분류가 달라져도 Activity와 WebView가 다시 만들어지지 않도록 했습니다. 480×800 / 160dpi의 작은 화면과 Google 서비스가 비활성화된 테스트 기기에서도 공개 서버를 대상으로 앱 검사 3개를 모두 통과했습니다. GitHub 검사도 프로덕션 서버 빌드를 사용합니다.

현재 APK는 이 작업 PC의 디버그 키로 서명했습니다. 이전 1.0.0 배포 APK와 인증서가 달라 기존 설치 위에 바로 업데이트할 수 없습니다. 이전 앱의 그림을 유지하면서 멀티플레이만 사용하려면 재설치 없이 연결 설정에 공개 서버 주소를 입력하세요. 자동 가로 전환을 쓰려면 새 APK가 필요하며, 기존 앱을 삭제하면 기기에 저장한 그림도 삭제됩니다.

설치용 파일은 `releases/DrawDerby-debug.apk`입니다. SHA-256은 옆의 `.sha256` 파일에 기록합니다. Google Play 배포용 서명은 하지 않았습니다.

GitHub Actions의 Android 14 에뮬레이터에 실제 APK를 설치해 실행 검사 3개를 모두 통과했습니다. 네트워크 요청을 차단한 상태에서 네 트랙의 경주 결과와 그림 저장을 확인했고, 연결 실패 후 오프라인 복귀와 앱을 호스트로 하는 4인 온라인 경주 시작도 확인했습니다. 웹 검사부터 APK 빌드·설치·실행까지의 [검증 결과](https://github.com/shaunkimdev/horserace/actions/runs/34771108843)를 확인할 수 있습니다.

실제 휴대폰과 다른 Android 버전의 실행 검사는 아직 수행하지 않았습니다. 로컬 Windows 에뮬레이터는 디스크 공간 부족으로, GitHub의 Android 16 에뮬레이터는 게스트 시스템 중단으로 검사를 완료하지 못했습니다.
