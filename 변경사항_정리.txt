[드로우 더비 (Draw Derby) 업데이트 변경사항 정리]
버전: 1.5.0 (versionCode 7)

1. 친구와 경주 - 카카오톡 초대 기능 추가
- 대기방 상단 초대 코드 복사 버튼 옆에 [카카오톡으로 보내기] 버튼(.kakao-share-button) 추가
- 전달 메시지 포맷:
  [드로우 더비] 내가 그린 동물로 함께 달려요!
  초대 코드: (6자리 방 코드)
  바로 참가하기: (방 참가 링크)
- Android 앱 내 실행 시:
  - 네이티브 브리지(DrawDerbyScreen / drawderby://kakao)를 통해 카카오톡(com.kakao.talk) 앱 공유 창을 직접 실행
  - 카카오톡 미설치 환경에서는 초대 메시지를 클립보드에 자동 복사하고 안내 토스트 표시
  - 구버전 서버 접속 시에도 대기방에 카카오톡 공유 버튼이 자동 표시되도록 폴백 스크립트 적용
- 모바일/데스크톱 웹 브라우저 실행 시:
  - 초대 메시지를 클립보드에 복사하고 Web Share API(navigator.share) 지원 환경에서는 시스템 공유 시트를 호출

2. 방 만들기 옵션 강화 (방 제목 / 공개·비공개 / 4자리 비밀번호)
- 방 제목 설정:
  - 모바일 화면 비율을 고려해 최대 15자(ROOM_TITLE_MAX_LENGTH = 15)로 제한
  - 미입력 시 기본 방 제목("${선수이름}의 달리기방") 자동 적용
  - 대기방 상단에 방 제목 및 공개/비공개 배지 표시
- 공개방 / 비공개방 선택:
  - 방 생성 시 [공개방] 또는 [비공개방] 선택 가능
  - [비공개방] 선택 시 숫자 4자리 비밀번호(0000~9999) 입력 필수
  - 비공개방 참가 시 4자리 비밀번호 검증(불일치 시 403 반환), 방 스냅샷 응답에는 비밀번호(pin)가 노출되지 않도록 보호

3. 열린 대기방 목록 조회 및 새로고침 기능 추가 (추가 서버 비용 없음)
- 상시 폴링 없이 [친구와 경주] 탭 진입 시 1회 및 [새로고침] 버튼 클릭 시에만 열린 대기방 목록(GET /api/rooms) 조회
- 방 생성/참가/퇴장/경주 시작 등 실제 상태 변경 시에만 디렉터리 Durable Object(__DIRECTORY__) 요약 정보 갱신
- 열린 대기방 목록에서:
  - 공개방은 [바로 입장] 버튼으로 코드 입력 없이 즉시 입장
  - 비공개방은 [비밀번호 입장] 클릭 후 숫자 4자리 비밀번호를 입력하여 바로 입장
  - 기존 6자리 초대 코드 입력란에서도 비공개방 비밀번호 함께 입력 가능

4. Android APK 업데이트 반영
- AndroidManifest.xml: 카카오톡 패키지(com.kakao.talk) <queries> 가시성 선언 추가
- MainActivity.java: 카카오톡 공유 인텐트 연동 및 브리지 핸들러 추가
- DrawDerby-debug.apk (1.5.0, versionCode 7) 오프라인 웹 번들 및 APK 재빌드 반영
