# 공통 서체

Pretendard 1.3.9를 웹과 Android에 로컬로 포함합니다. 웹/WebView는 WOFF2, Android 네이티브 버튼은 TTF를 사용합니다. 앱 실행 시 외부 폰트 서버에 연결하지 않습니다.

- 원본: https://github.com/orioncactus/pretendard/tree/v1.3.9
- WOFF2: packages/pretendard/dist/web/variable/woff2/PretendardVariable.woff2
- TTF: packages/pretendard/dist/public/variable/PretendardVariable.ttf
- 라이선스: 동봉한 OFL.txt (SIL Open Font License 1.1). 원본 파일을 수정하지 않았습니다.
- 앱 내 오픈소스 안내에도 라이선스 전문을 포함합니다.
