# DRAW DERBY

reference1·2의 라임색 그림판과 손그림 동물 경주를 바탕으로 만든 웹 게임입니다. 마우스·터치로 동물을 그리고, 다리 길이와 간격 및 몸통 비율에 따른 자동 장애물 경주를 즐깁니다.

## 실행

Node.js 24 이상을 권장합니다. 이 `game` 폴더에서 실행하세요.

```sh
npm ci
npm run dev -- --hostname 0.0.0.0
```

브라우저에서 `http://localhost:3000`을 엽니다. 처음 실행하면 로컬 D1 저장소를 자동으로 준비합니다. 같은 네트워크의 친구는 이 컴퓨터의 LAN 주소와 3000 포트로 접속할 수 있습니다. Windows 방화벽에서 해당 연결이 허용되어 있어야 합니다. 서로 다른 네트워크에서는 배포된 HTTPS 주소를 사용하세요.

## 게임 방법

1. 예시 그림을 수정하거나 지우고 새로운 동물을 그립니다. 오른쪽을 향한 몸통과 떨어진 다리를 2개 이상 그려주세요.
2. 선수 이름, 트랙, 플레이 방식을 선택합니다. 트랙 카드에서 내 그림의 예상 기록과 유리한 형태를 확인하세요. **혼자 연습**은 서로 다른 체형의 AI 3마리와 경주합니다.
3. **친구와 경주 → 새 대기방 만들기**에서 초대 링크 또는 6자리 코드를 공유합니다. 친구는 **참가하기**로 입장합니다.
4. 방장이 트랙을 고르고 2~4명이 모두 준비하면 출발합니다. 트랙을 바꾸면 모든 참가자의 준비 상태가 해제됩니다. 달리기·점프·회전은 자동입니다.
5. 완주 기록·충돌·점프 횟수를 보고, 다리를 다시 그리거나 재경기를 진행합니다.

## 형태와 장애물

| 트랙 | 형태 | 유리한 체형 |
| --- | --- | --- |
| 쭉쭉 허들 직선 | 높은 허들·물웅덩이가 이어지는 직선 | 긴 다리, 넓은 보폭 |
| 빙글빙글 원형 경기장 | 큰 코너를 돌아오는 원형 한 바퀴 | 넓은 다리 간격, 낮은 무게중심 |
| 갈팡질팡 지그재그 | 급한 방향 전환과 돌길 | 짧은 몸통, 짧고 안정적인 다리 |
| 납작납작 S자 숲길 | 직선과 S자 곡선, 낮은 터널과 진흙 | 낮은 체형, 안정적인 발 간격 |

화면과 시뮬레이션은 같은 곡선 경로를 사용합니다. 회전 각도와 형태별 균형 능력에 따라 속도가 줄거나 미끄러지고, 급회전의 펜스 충돌도 기록됩니다. 원형 트랙의 바깥쪽 레인을 포함해 모든 레인은 정규화된 1,000m이며 레인 순서는 결과에 영향을 주지 않습니다. 예상 기록은 현재 그림과 고정된 기준 장애물로 계산한 값입니다.

- 다리 길이: 보폭과 허들 통과 능력에 영향을 줍니다. 너무 긴 다리는 돌길에서 불리할 수 있습니다.
- 다리 간격: 물웅덩이 통과, 착지 안정성, 진흙과 돌길에 영향을 줍니다.
- 몸통 높이·길이: 낮은 터널 통과와 진흙 감속에 영향을 줍니다.
- 코스: 허들, 물웅덩이, 진흙, 낮은 터널, 돌길이 매번 다른 순서와 크기로 나옵니다.

그림을 격자 형태로 분석하는 게임 규칙이며 동물 종을 인식하는 AI나 정밀한 물리 시뮬레이션은 아닙니다. 그림을 전체적으로 확대하거나 이동해도 능력은 유지됩니다. 최대 80획, 획당 1,500점, 전체 8,000점을 허용합니다.

## 질주 연출과 소리

네 트랙 모두 쭉쭉 허들 직선과 같은 근접 추적 시점과 확대 배율을 사용합니다. 내 동물이 같은 크기와 화면 위치를 유지하고, 원형·지그재그·숲길에서는 카메라가 실제 곡선의 진행 방향을 따라 회전합니다. 장애물과 울타리도 같은 곡선 위에 놓이며, 모바일에서도 모든 트랙에 같은 화면 확대 규칙을 적용합니다.

원형은 양끝을 더 둥글게, 지그재그와 숲길은 큰 반경으로 방향을 바꾸도록 구성했습니다. 가까운 화면에서는 도로의 회전각을 완만하게 펼쳐 보여 주므로 코너가 갑자기 세워지거나 안쪽 레인이 접히지 않습니다. 이 표현은 이동 거리 기준으로 계산해 멀티플레이와 재접속에서도 동일합니다.

질주 속도를 기존의 1.7배로 높이고 장애물 회복 시간도 같은 비율로 줄였습니다. 다리 동작은 실제 이동 거리를 따라가며, 큰 보폭·몸통 반동·점프 중 다리 접기·착지 압축과 먼지·코너 미끄러짐을 표현합니다. 화면은 최대 60fps로 갱신하고, 기기의 동작 줄이기 설정에서는 화면 흔들림과 추가 입자 효과를 줄입니다.

출발하면 164 BPM의 오리지널 드럼·베이스·신스 배경음이 재생됩니다. 마지막 200m에는 하이햇과 멜로디가 더 촘촘해지고, 점프·충돌·착지·완주에도 효과음이 나옵니다. 상단 **소리 켜짐/꺼짐** 버튼은 음악과 효과음을 함께 제어합니다. 경주를 나가거나 탭을 숨기면 소리가 멈추며, 돌아오면 현재 경주 시점부터 이어집니다. 별도 음원 다운로드나 외부 음악 서비스 없이 Web Audio로 합성합니다. 브라우저 정책에 따라 첫 버튼 클릭 후 소리가 활성화됩니다.

## 멀티플레이 구조

React 19 + vinext + Cloudflare Workers/D1을 사용합니다. 서버가 방의 정원·준비 상태·시작 권한을 검사하고 참가자 그림과 출발 시각·시드를 확정합니다. 각 클라이언트는 같은 결정론적 엔진으로 경주를 표시하고, 서버가 계산한 것과 동일한 결과를 얻습니다. 대기방과 접속 상태는 약 1.5초마다 갱신하며 늦게 도착한 응답은 버전 번호로 제외합니다.

참가 토큰은 탭의 `sessionStorage`에 저장하여 새로고침 후 복귀합니다. D1에는 토큰 해시만 저장합니다. 그림 초안은 기기에만 저장합니다. 대기방에서 1분 이상 응답이 없는 참가자는 정리되고 방장은 자동으로 이전됩니다. 사용하지 않는 방은 2시간 후 만료됩니다. 공유 링크에는 참가 토큰이 포함되지 않습니다.

Sites 배포는 `.openai/hosting.json`의 `DB` 바인딩과 `drizzle` 마이그레이션을 사용합니다. 사이트의 기본 접근 권한은 소유자 전용입니다. 다른 사람과 인터넷으로 플레이하려면 사이트 공유 설정에서 참가자의 접근을 허용하거나 공개로 전환해야 합니다.

## 검증

```sh
npm test
npm run lint
npx tsc --noEmit
npm run build
```

개발 서버가 실행 중이면 실제 HTTP 연결로 4인 입장·시작·결과 동기화도 검사할 수 있습니다.

```sh
npm run test:server
```

형태 분석과 100개 코스 균형, 빠른 경주의 예상 기록·착지 동작, 결정론적 결과, 실제 D1 동시 입장, 권한·정원·재접속·재경기 및 입력 검증 테스트가 포함되어 있습니다. 오디오 검사는 합성 스케줄러와 음소거·탭 전환·재경기·자동 재생 차단·노드 정리를 검증합니다. UI는 데스크톱과 모바일 반응형이며, 키보드 사용자는 예시 동물 버튼으로 참여할 수 있습니다.
